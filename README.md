# Sales Forecasting Using ARIMA Time Series Analysis

## 📌 Project Overview

Sales forecasting helps businesses estimate future sales using historical data, enabling better inventory management, production planning, and business decision-making.

This project applies the ARIMA (AutoRegressive Integrated Moving Average) time-series forecasting model to analyze historical sales data and predict future sales. The project also explores trend, seasonal, and promotional patterns through Exploratory Data Analysis (EDA).

---

## 🎯 Objectives

- Analyze historical sales data.
- Perform Exploratory Data Analysis (EDA).
- Identify trend, seasonal, and promotional patterns.
- Build a sales forecasting model using ARIMA.
- Forecast future sales.
- Evaluate model performance using MAE and RMSE.
- Compare forecasted sales with actual sales.
